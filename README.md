## 📖 Sobre o projeto

**Nenhuma Pata Para Trás** é uma aplicação web desenvolvida para conscientizar a população sobre a importância da proteção e do bem-estar animal.

O site reúne informações educativas baseadas na legislação brasileira, abordando:

- Maus-tratos aos animais;
- Abandono e negligência;
- Impactos sociais e ambientais;
- Guarda responsável;
- Legislação de proteção animal;
- Canais oficiais de denúncia;
- Promoção da adoção consciente.

O projeto foi desenvolvido utilizando apenas tecnologias Front-End, priorizando acessibilidade, responsividade e uma experiência de navegação intuitiva.

## 🚀 Como executar

```bash

```

Entre na pasta:

```bash
cd nenhuma-pata-para-tras
```

Abra o arquivo:


em qualquer navegador moderno.

Não é necessário instalar dependências.
